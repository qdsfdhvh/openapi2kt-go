## Status definitions

- **Existing implementation**: a current feature contract, source, and test entry point exist; coverage is limited to inputs and contexts accepted by the contract.
- **Feature gap**: a capability is currently rejected, approximated, or absent and needs an explicit incremental contract before implementation. Completing a bounded subset does not complete the corresponding compatibility matrix item.
- **Awaiting acceptance**: an implementation exists, but execution evidence for the same candidate, toolchain, options, or target platform has not been closed as a whole. Existing tests do not mean the candidate passed.
- **Later/out of scope**: full YAML exceeds the implemented JSON-compatible adapter profile; external specification acquisition, a formal Gradle plugin, and similar work are outside current product delivery. Declared approximations do not automatically become features that must be rewritten.

This page does not record local execution logs, assign completion percentages without a common denominator, or change existing support or release scope. Linked feature contracts define precise input boundaries; actual candidate results are verified separately under R01–R08.
