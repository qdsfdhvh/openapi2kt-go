## 状态口径

- **已有实现**：存在当前功能合同、源码和测试入口；只覆盖合同接受的输入和上下文。
- **功能缺口**：当前仍拒绝、近似处理或没有提供的能力，需要先明确增量合同再实现。一个有界子集完成，不等于对应兼容矩阵整项完成。
- **待验收**：实现已有，但同一候选、工具链、选项或目标平台的运行证据尚未统一关闭。不能把“测试存在”写成“本候选已通过”。

本页不记录本地运行日志，不给没有统一分母的完成百分比，也不改变既有支持或发布范围。精确输入边界以链接的功能合同为准；实际候选结果按 R01–R08 单独核验。
