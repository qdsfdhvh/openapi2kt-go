# Borrowed collections with named caller-native leaves

Finite internal List/typed Map segments and root container exports may end at original named scalar or type-omitted caller-native components and supported aliases. Original `x-native-type` string/schema/Pointer, canonical owner, semantic node identity and one actual retained ScalarAlias or nullable ValueAlias authorize the leaf. The caller supplies the real classifier, construction API and serializer. No generated replacement class or inferred codec/layout is introduced.

[Named caller-native chains](caller-native-reference-chains.md) supply source authority. Provider Money keeps its real string codec and API. Caller Long uses JSON numbers and never acquires the magic bigint field helper. ByteArray nested in containers/Patch/DTO/SSE uses provider signed arrays; String, JsonElement, JsonObject and Instant retain their provider codecs. Coincident Kotlin spellings keep separate magic date/bigint, byte/binary, raw/true and recursive JSON source roles. Native standalone String/ByteArray HTTP bodies retain their existing raw projection; borrowed List/Map roots are JSON containers.

Nearest explicit nullable/false intent remains path-local, independent for container and item/value. False narrowing preserves complete cached source work. Transparent aliases introduce no nominal recursion barrier. Source48, checked collection16, work16,384 and serialized JVM slots240 remain. Collections retain reference slots; the real Money sample and independent resource probes do not establish arbitrary provider inline-class layout or Android/KMP safety.

Counts remain opt-in at DTO/Patch.Value/HTTP preflight-postflight/SSE payload boundaries. Bare native collection codecs do not enforce counts. Shared optional null defaults and request required-null/Patch absent/null/value retain their contracts. Non-null caller JsonElement can carry JsonNull; nullable provider codecs retain their existing collapse behavior. Provider malformed-kind/syntax/null errors and cancellation close still-open fragmented SSE input; cold collection and subsequent client reuse remain valid. Native generation failures preserve owned output.
