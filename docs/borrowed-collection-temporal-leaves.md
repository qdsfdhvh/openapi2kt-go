# Borrowed collections with named temporal leaves

Finite internal List and typed Map segments and root container exports may reuse original named date/date-time or `x-native-type: date` scalars and supported aliases. Kotlin backing remains `kotlin.time.Instant` or `kotlinx.datetime.LocalDate`, using the existing provider serialization/ISO parsing contract. No wrapper, DTO or copied scalar source is introduced.

Admission shares [temporal reference chains](temporal-reference-chains.md). The original canonical component/schema/Pointer, format/native source role, semantic node identity and one actual retained ScalarAlias or nullable ValueAlias export authorize the leaf. Missing/replaced/repeated declarations, changed mapping or same-byte source copies are rejected. Caller-native classes that happen to use the same Kotlin type name do not acquire temporal permission.

Forward aliases use the existing catalog DFS and preserve nearest nullable/ref/consumer intent. Container and item/value nullability remain independent; false narrowing keeps complete cached source work. Temporal aliases are transparent and introduce no nominal recursion barrier. Source depth48, checked collection edges16, work16,384 and JVM slots240 remain fixed; separate probes do not guarantee combined resource maxima or additional platforms.

Container counts are opt-in at DTO/Patch.Value/HTTP pre-postflight/SSE payload boundaries. Provider codecs own temporal parsing; malformed ISO or wrong JSON kind fails decoding. Bare collection codecs do not enforce container counts. Shared/default-null and inline required-null/Patch contexts keep their existing contracts. Structured parameter projection/diagnostics and ISO wire behavior remain unchanged. Native generation failures preserve old output; fragmented SSE parse/null/container failures and cancellation close still-open input, followed by cold collection/client reuse.

**Migration:** previously rejected borrowed containers ending at actual named temporal sources now reuse native backing and original codecs. Existing accepted APIs/wire and opt-in defaults remain. Named bigint/bytes/caller-native/raw/true collection leaves, general common/intersection graphs and Android/KMP need separate contracts and evidence.
