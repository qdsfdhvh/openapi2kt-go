# Borrowed collections with named builtin scalar leaves

Finite schema-internal List and typed Map paths, and component root exports of those containers, may reuse original named String, Boolean, Int, Long, Float and Double scalars and their supported aliases. Kotlin backing remains native: a nullable String leaf yields `List<String?>`, while a Long value yields `Map<String, Long>`. Containers do not invent scalar wrappers or physical DTO classifiers.

Admission shares the [named builtin reference contract](builtin-reference-chains.md). The original canonical component/schema/Pointer, scalar mapping, check objects and actual retained scalar export authorize the leaf. Missing/replaced/repeated declarations, copied original schema nodes and changed scalar/check content are rejected. Forward supported aliases use existing catalog DFS; their nearest nullable intent and complete original source height remain. Legacy unmarked non-null aliases keep their existing opt-in policy.

Builtin scalars are transparent and do not introduce a nominal recursion barrier. Every incoming named/internal reference and collection edge counts toward source48. Container and element nullability remain independent, with explicit false narrowing retaining full cached source work. Checked collection edges16, work16,384 and constructor/method slots240 stay unchanged. A collection occupies one slot; these independent limits are not combined platform resource guarantees.

Validation opt-in propagates original native scalar checks through typed constructors/copy, automatic serde, Patch.Value, HTTP pre-postflight and SSE payloads alongside container counts. Bare native scalar/collection assignment and standalone codecs do not validate constraints. Required nullable inline requests and optional nullable Patch retain their established policies. Long remains numeric in JSON collections and SSE; no bigint helper or caller-native codec permission is added.

Structured parameters keep existing projection and warnings. Invalid original source preserves old output. Fragmented SSE bad scalar/container/null/malformed data and cancellation close still-open channels; repeated cold collection and client reuse retain their existing contract. General union common-field Map projections, special scalar roles, raw/true JSON and arbitrary recursive/composition graphs remain separate.
