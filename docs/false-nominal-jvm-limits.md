# Known false-class JVM descriptor limits

The generator rejects a provably oversized JVM descriptor involving direct fields of an actual retained [false component](false-component-roots.md) or owner-nested [literal-false codec](literal-false-fields.md). A long package or classifier name can exceed the JVM's 65,535-byte modified UTF-8 constant limit with fewer than 240 constructor slots.

The check runs after final model style and shape transformations. It derives nominal lengths from actual emitted `FalseValue` declarations and their lexical owners. A `Named` spelling alone grants no such knowledge: arbitrary aliases, value classes and unknown classifiers are omitted. Nullable wrappers preserve the actual reference descriptor. Known erased List/Map and builtin scalar parameters contribute only their erased descriptor costs; generic argument text is not counted in an erased descriptor.

Constructors and Data `copy$default` are separate. The static copy method includes the explicit receiver, all property parameters, mask integers, Object marker and return classifier, including for required properties. Plain classes have no Data copy API and retain their independently admissible constructors. Existing [generic signature](jvm-signature-limits.md), [List variance](jvm-list-variance-limits.md) and [Data copy signature](jvm-copy-signature-limits.md) lower-bound checks remain in force.

**Migration:** some previously generated sources that failed Kotlin compilation with `UTF8 string too large` now fail generation with `E_MODEL_LIMIT` at the original component Pointer and no artifacts. Native generate, check and validate preserve existing output. Within-budget output and ownership/name-lock formats remain compatible. Splitting the model or shortening names can reduce descriptor size. Choosing Plain style removes the Data copy methods and changes the public model API, so choose it deliberately.

The erased check is conservative: it requires a direct actual false nominal field and omits unknown classifier lengths and synthetic serializer/default constructors. Actual false classifiers in collection arguments have a separate [generic constructor/instance copy bound](false-generic-jvm-limits.md). Passing these checks does not prove all JVM constants, method bodies, metadata or platform limits. Existing source48, false-work16,384, value16,384, default32KiB, checked16, JVM slots240 and enum240 limits remain.

`bash scripts/test.sh feature false-nominal-signatures` freshly compiles and runs baseline and optimized Data/Plain resource controls, including strict missing/null behavior and Data copy. For the synthetic 316-byte package and `WideDto` owner, Data188 compiles with a 65,364-byte `copy$default` descriptor and Plain190 compiles with a largest UTF-8 constant of 65,432 bytes; Data189 and larger known-impossible constructor cases reject. These dimensions are specific probes, not general field-count caps. [Core limits](../core/false_nominal_signatures_test.go), [bounded fuzzing](../core/false_nominal_signatures_fuzz_test.go) and [native preservation](../internal/cli/false_nominal_signatures_process_test.go) retain deterministic results and original source Pointers. Existing deep-list and 240-field probes remain independent.
