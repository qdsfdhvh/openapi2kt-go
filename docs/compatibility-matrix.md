### M07: field states to test separately

The following applies to **inline object requests and their recursive inline subtrees**. Referenced components do not split request/response types and retain ordinary nullable models; root union requests, responses, and deepObject do not enable Patch. Union properties in inline objects inherit context; this does not enable Patch for root union requests.

| required | schema nullable | Request body Kotlin | Key wire behavior |
|---|---|---|---|
| Yes | No | `T` | Value is required |
| Yes | Yes | `T?`, no default | Null or a value must be passed; with `explicitNulls=true`, null has a key independently of `encodeDefaults` |
| No | No | `T? = null` | Omitted when absent; non-null sends a value. This does not strictly express every invalid state |
| No | Yes | `Patch<T> = Patch.Absent` | Absent is omitted, Null sends null, Value sends a value |

- Nullable response properties may remain `T? = null`; const does not enter Patch.

Verify all combinations of both settings without extrapolating one request context to other contexts or configurations.
