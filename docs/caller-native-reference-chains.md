# Finite reference chains to named caller-native scalars

Typed internal references may follow finite `$ref`/nullable-only paths to an original named scalar or type-omitted caller-native component or eligible alias. Root bridges and later named/internal chains retain its original `x-native-type` string, native Scalar backing, catalog Schema/Pointer and actual retained generator alias. The caller supplies the real classifier and serializer; no generated DTO replaces it.

## Source permission and provider ownership

A matching Kotlin classifier alone grants no source role. The original accepted native grammar/node/Pointer/source snapshot and unique retained ScalarAlias or intrinsic nullable ValueAlias authorize chains. Missing/replaced/duplicate declarations, copied source and changed marker/layout reject. First HTTP/union uses and final validation share the same resolver authority. Structured native schemas, enum/const/wrapper and borrowed internal native leaves retain separate policies; no-chain controls establish excluded terminal keyword errors separately from early chain rejection.

From consumer to terminal along the real transparent path, nearest explicit nullable true/false wins; absent inherits cached suffix and intrinsic intent. Root-before-hop and hop-before-root order are preserved. False uses original non-null provider backing and full named/internal source work; aliases add no nominal barrier.

Existing depth48/work16,384/slot240 limits remain. Known native Long/Double consume two non-null JVM slots and one nullable slot. Other provider names use current one-slot planning, which does not establish arbitrary inline-class physical-layout safety. The synthetic Money provider and bounded JVM inputs are tested; other provider APIs/layouts and platforms require separate evidence.

## API and wire contracts

A real Money sample declaration owns construction and string serialization. Alias constructors/companion serializers where supplied, reified nullable adapters and consumer copy retain that provider API. Caller Long stays numeric even alongside magic bigint; it never acquires LongAsStringSerializer. ByteArray model/ListMap/Patch/SSE uses provider signed arrays, while caller ByteArray/String Ktor roots remain raw values including null ASCII. Malformed JSON bytes remain raw HTTP responses.

Caller JsonElement/JsonObject and Instant retain their real provider codecs and nullable behavior. Nullable JsonElement collapses JsonNull to Kotlin null; Patch.Value(JsonNull) encodes null and decodes as Patch.Null. Sharing erasure with raw/true/cover or temporal markers does not share their source/warning/graph roles. Method suffix allocation uses the real backing classifier, not an invented nominal type.

Fragmented still-open SSE payloads use the provider decoder, close on bad kind/syntax/null or cancellation and remain cold/reusable. Reconnect/resume remains caller-owned.
