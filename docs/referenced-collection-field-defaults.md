## Annotation and presence

Only the consuming field's own default is accepted. Existing nearest-annotation precedence concerns **nullable**, not default inheritance. A default on a referenced target, any intermediate reference, a container child or scalar leaf remains rejected, including when the consumer has its own default. No target value is inherited, discarded or selected by a collision rule. Component/root defaults and `allOf` reference-wrapper defaults remain separate roles.

Nullable intent follows the existing reference contracts: nearest explicit consumer/alias true or false, terminal intent and the historical direct dictionary policy. Every container and scalar layer stays independent. Optional presence alone does not legalize a null annotation. Optional ordinary fields get a typed constructor/decoding initializer; explicit JSON null remains null and a supplied value replaces the default. Required fields validate the annotation and keep required constructor arguments, including required nullable fields. Optional explicitly nullable inline request fields retain `Patch.Absent`, with separate Null and Value wire states. A default does not create an update for a missing request key. `explicitNulls = false` retains the existing missing-required-null inference; this is not strict required-key validation.

The role is available in ordinary shared/nested DTOs and ordinary inline request/response/SSE payload DTOs. Ordinary object `allOf` retains its later-property override contract and validates discarded original defaults. Discarded checks without an existing aggregation contract still reject. Union/hierarchy fields, nominal DTO leaves (the separate [referenced object collection contract](referenced-object-collection-defaults.md)), union/hierarchy/enum/native/value-class leaves, raw/open dictionaries, nullable composition folds and wider default roles remain outside this profile. Standard temporal leaves use the separate extension above. Direct inline trees use the separate [nested builtin contract](nested-builtin-collection-defaults.md).
