# Borrowed collections with named raw and literal-true leaves

Finite internal List/dictionary segments and root container exports may end at original named raw empty ordinary objects or literal `true` components and eligible aliases. Raw requires one retained original empty Model with no properties/constants/nested declarations/property counts; empty supported allOf can qualify. Literal true requires its original JSON ValueAlias. The original catalog/schema/Pointer/semantic nodes/actual declaration authorize the leaf, independently of aliases or Kotlin spelling. Const-only/nonempty/hierarchy/union/dictionary models and recursive covers keep separate roles.

[Named raw/true chains](raw-true-reference-chains.md) supply source authority. New root-bound borrowed Lists expose transparent JsonElement backing. Nullable leaves collapse JSON null to Kotlin null, while non-null JSON elements retain JsonNull. Raw dictionary values retain the existing JsonObject approximation, including JsonNull entries, rather than a generic Map API. Direct historical container callers can retain the original raw public alias spelling and codec. JSON strings, numbers, booleans, arrays and objects remain accepted; no raw object-kind validator is introduced.

Nearest explicit nullable/false intent is independent for container and leaf. False narrowing retains complete cached source work. Transparent JSON aliases introduce no nominal barrier. Source48/checked collection16/work16,384/serialized JVM slots240 remain; independent probes do not prove simultaneous limits or actual Android/KMP. Recursive covers require their separate full original graph/SCC permission.

Original raw roots own `W_JSON_ELEMENT_APPROXIMATION`, true roots own `W_BOOLEAN_SCHEMA_PROJECTION`, and empty allOf retains its composition warning. Borrowed users do not duplicate source warnings. Original grammar/ref siblings/defaults and constraints are validated; warning denial preserves previous output before IO. Typed container counts remain opt-in at DTO/Patch.Value/HTTP preflight-postflight/SSE payload boundaries, with bare List/JsonObject codecs unchanged. Shared defaults and request required-null/Patch absent/null/value retain their contracts; `Patch.Value(JsonNull)` keeps the existing null collapse rather than introducing a fourth state.
